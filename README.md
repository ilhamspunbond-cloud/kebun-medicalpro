# Ladang Belimbing Buluh Medical Pro & ILHAM SPUNBOND (Fully Modular)

Sistem web bersepadu dengan struktur fail HTML yang dipecahkan sepenuhnya kepada bahagian-bahagian kecil (partials) agar lebih kemas dan mudah diselenggara di GitHub.

## Struktur Direktori
- `index.html`: Kerangka utama halaman web.
- `style.css`: Fail gaya reka bentuk responsif.
- `components/sidebar.html`: Komponen menu navigasi sisi.
- `components/topbar.html`: Komponen bar atas (profil dan butang menu).
- `app.js`: Skrip pemuatan komponen secara dinamik serta pengurusan modul.
